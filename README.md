# Яндекс Спейс — прототип

Учебный прототип сервиса, который показывает свободные столики в кафе Казани в реальном времени
и даёт забронировать их без звонка. Проект по дисциплине «Маркетинг и рыночная аналитика».

## Запуск на Windows

Скачайте `YandexSpace-0.1.0-portable.exe` и запустите. Установка не нужна, интернет тоже.
Если Windows SmartScreen предупредит о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».

## Сценарий показа на защите (≈1 минута)

1. Приложение открывается интро-роликом (≈8 с, со звуком; «Пропустить» или `Esc` — сразу к карте),
   затем диорамой центра города и окном «Что хотите сделать?».
2. Выберите **«Спокойно посидеть и поработать»**: на карте появятся только подходящие места.
3. Нажмите на маркер «Бульвар Кофе»: откроется карточка с особенностями, загруженностью по часам и схемой зала.
4. Нажмите на зелёный столик → «Забронировать» → «Подтвердить бронь» → «Забронировано!».
5. Смените цель на **«Быстро найти свободный столик рядом»** и откройте «Полночь»: мест нет.
   Нажмите «Сообщить, когда освободится · 49 ₽». Через ~7 секунд придёт push, что столик освободился.
6. **«Найти место для большой компании»**: число гостей меняется, и список заведений сразу пересчитывается.

Горячие клавиши: `1`–`4` выбирают цель в стартовом окне, `Esc` закрывает верхний слой.
Карту можно двигать мышью и масштабировать колесом.

## Как поменять данные

Заведения, их особенности, загруженность и планы залов лежат в `app/data.js`.
Заведения и цифры вымышленные.

## Сборка

```bash
npm install
npm start        # запустить в режиме разработки
npm run dist     # собрать dist/YandexSpace-0.1.0-portable.exe
```
