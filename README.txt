КАК ОТКРЫТЬ ПРЕЗЕНТАЦИЮ «ЯНДЕКС СПЕЙС»

1. Сначала РАСПАКУЙТЕ архив: правая кнопка мыши по ZIP → «Извлечь всё…» → «Извлечь».
   Не открывайте файл прямо внутри архива — тогда видео не загрузятся.
2. В распакованной папке откройте presentation.html (двойной щелчок).
   Лучше в Google Chrome, Яндекс Браузере или Microsoft Edge.
3. Папка videos должна лежать рядом с presentation.html. Не переносите файл отдельно.

Управление: стрелки / пробел / кликер — листать; F — на весь экран; L — лёгкий режим (если тормозит).
Интернет не нужен.
